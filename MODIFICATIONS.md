# Modifications

This repository is a modified fork of the EasyTier documentation site:

https://github.com/EasyTier/easytier.github.io

It is maintained for the `wx2020/EasyTier` private build and is not the official EasyTier documentation distribution.

## Summary

- Rebranded the site as `wx2020 EasyTier`.
- Changed repository, issue, release, edit, install, and download links to `wx2020/EasyTier` or `wx2020/easytier.github.io`.
- Added Chinese and English private deployment documentation.
- Updated the homepage to describe the private modified build.
- Removed homepage community, sponsor, and acknowledgment links from the upstream site.
- Removed the upstream Aliyun OSS upload step from the GitHub Pages deployment workflow.
- Changed release version lookup and download links to use `wx2020/EasyTier`.
- Updated config-file documentation to avoid the official online config assistant in private builds.
- Added this `NOTICE` file and modification record for Apache License 2.0 compliance.
